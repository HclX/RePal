# App icon credits

The RePal app icon (ink-brush 仙, ink-wash mountains, red 剑 seal on xuan paper) is generated by
`tools/make_app_icon.py`. To change it, edit that script and re-run it; it rewrites every size in
this directory.

The brush character and seal text are rendered with **Ma Shan Zheng** (马善政毛笔楷书),
Copyright 2018 The Ma Shan Zheng Project Authors, licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/) —
<https://github.com/google/fonts/tree/main/ofl/mashanzheng>. The font itself is not redistributed
in this repository (the script downloads it at build time); only rendered images are included.
